# Jiru's personal site

This is a dependency-free static site designed for GitHub Pages.

## Publish it

1. Create a **public**, empty GitHub repository named `jiru-unsw.github.io` under `jiru-unsw`.
2. Push this folder's `main` branch to that repository.
3. In the repository's **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

GitHub will publish the site at `https://jiru-unsw.github.io/` after the deployment completes.

## Add a post

Copy `posts/welcome.html`, give it a short URL-safe file name, then add a card to the **最近笔记** section in `index.html`.

## Personalize

- Replace the three placeholder project cards in `index.html`.
- Change the text in the About section.
- Update the GitHub handle if it ever changes.
